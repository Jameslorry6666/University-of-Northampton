## Dataset Information
The dataset consists of raw gaze coordinates (x,y) of 24 participants while they were performing desktop activities (READ). All the activities were 5 minutes long. The eye movements were recorded using a desktop mounted Tobii X2-30 eye tracker and Tobii Pro Studio software.

## Overview
This project focuses on developing low-latency gaze estimation algorithms and predictive models to assist individuals with ALS.

## Contents
- U_O_N_ALS.ipynb - Main Jupyter notebook with analysis

## Research Areas
1. Low-latency gaze estimation algorithms
2. Predictive models to reduce delay
3. User experience measurement
